## 🎮 Nové Funkcie (Väčšia Mapa & Návrat do Hry)

* **▶️ Tlačidlo "POKRAČOVAŤ V HRE (SPÄŤ)"**: Keď otvoríš menu počas hrania, na vrchu menu sa zobrazí zelené tlačidlo pre okamžitý plynulý návrat späť do tvojej rozohratej 3D hry!
* **🧭 Zväčšená 2D Live Minimapa**:
  * Zväčšená veľkosť mapy na **145x145 dp** pre výrazne lepšiu prehľadnosť.
  * Zobrazuje koncentrické kruhy radaru, severný kompas **N**, zvieratá (biele), monštrá (červené), Bossa (fialový) a postavené ohniská a prístrešky!
