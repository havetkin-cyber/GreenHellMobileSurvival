## 🌴 3D Low-Poly OBJ Modely & Renderovanie

* 🌴 **`palm_tree.obj`**: 3D Low-Poly model palmy s kmeňom a listami.
* 🌳 **`jungle_tree.obj`**: 3D Low-Poly model stromu džungle.
* 🪨 **`rock.obj`**: 3D Low-Poly model skaly a balvanu.
* 🪓 **`stone_axe.obj`**: 3D Low-Poly model kamenej sekery pre 1st-person pohľad z ruky.
* 🌿 **OBJ Model Parser (`ObjModel.kt`)**: Vlastný rýchly parser pre čítanie `.obj` modelov z assetov.
