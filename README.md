## 🎮 Vylepšenia UI & Hotbaru

* **🪓 3D Hotbar**: Plne funkčná 6-slotová lišta na spodku obrazovky s jasným výberom predmetov, ikonami a počtom kusov.
* **🧭 Live 2D Minimapa**: Integrovaný radar s kompasom a ikonami blízkych surovin, zvierat a monštier.
* **✋ Z-Order 3D Renderera**: Opravená vrstva dotykov tak, aby všetky tlačidlá, hodinky, batoh, mapa aj lišta reagovali okamžite na dotyk.
